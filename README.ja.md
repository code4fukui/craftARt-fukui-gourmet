# craftARt-fukui-gourmet

福井県の地元の食文化を3Dモデルで再現するARウェブアプリケーションです。このプロジェクトは、craftARtフレームワークを活用し、モバイルデバイスおよびVR/XRヘッドセットで没入感のある体験を提供します。

## デモ

**[https://code4fukui.github.io/craftARt-fukui-gourmet/](https://code4fukui.github.io/craftARt-fukui-gourmet/)**

アプリケーションはデバイスを自動的に検知し、最適な体験を提供します:
* **モバイル / デスクトップ:** Googleの `<model-viewer>` を使用した軽量なARビュー。
* **VR/XRヘッドセット:** Three.jsとWebXRで構築された完全な没入型シーン。

## 特徴

- **リアルな3Dモデル:** 福井県の有名グルメの高品質な3Dスキャンを表示します:
    - ヨーロッパ軒のカツ丼
    - あみだそばのおろしそば
    - 8番らーめんの野菜麻辣らーめん
- **インタラクティブなAR体験:** 身の回りの平らな場所に料理を配置できます。直感的なジェスチャーで回転、拡大縮小、移動が可能です。
- **料理情報:** 各アイテムの説明や、公式の店舗ページへのリンクにアクセスできます。
- **クロスデバイス対応:** モバイル最適化版またはヘッドセット最適化版へユーザーを自動的にルーティングします。

## 使い方

1. 対応ブラウザで[デモリンク](https://code4fukui.github.io/craftARt-fukui-gourmet/)を開きます。
2. ドロップダウンメニューから料理を選択します。
3. **モバイルデバイスの場合:**
    * 「ARスタート」ボタンをタップします。
    * 3Dモデルが表示されるまで、カメラを明るく平らな場所（テーブルや床など）に向けます。
    * タッチジェスチャー（ピンチで拡大縮小、ドラッグで回転）を使用してモデルを操作します。
4. **VR/XRヘッドセットの場合:**
    * 没入型体験が直接読み込まれます。
    * コントローラーを使用してシーンを操作します。

## 必要条件

このアプリケーションを利用するには、WebXR対応のデバイスとブラウザが必要です。
- **iOS:** Safari
- **Android:** Chrome
- **VR/XRヘッドセット:** WebXR対応ブラウザ

## 技術スタック

このアプリケーションはウェブ技術で構築されており、インストールの必要はありません。
- **データ:** モデルのメタデータは [`models.csv`](./models.csv) で管理されています。
- **モバイルAR:** [Google `<model-viewer>`](https://modelviewer.dev/) を使用。
- **ヘッドセットVR/XR:** [Three.js](https://threejs.org/)、[egxr.js](https://github.com/code4fukui/egxr.js)、およびWebXR APIを使用。
- **フレームワーク:** [craftARt-kit](https://github.com/echizencity/craftARt-kit) プロジェクトをベースにしています。
